# Техническое задание на разработку программы KeyTester

## 1. Назначение
Программа предназначена для визуального тестирования работоспособности клавиатур, фиксации нажатий, выявления залипших клавиш и сохранения отчетов о тестировании.

## 2. Функциональные требования (FR)
* **FR-1:** Программа должна загружать конфигурации раскладок из папки `layouts` в формате JSON.
* **FR-2:** Программа должна отображать виртуальную клавиатуру в соответствии с выбранным форм-фактором.
* **FR-3:** Программа должна подсвечивать клавишу при ее нажатии (цвет #A63928).
* **FR-4:** Программа должна возвращать клавишу в исходное состояние (цвет #FDAA9D) при отпускании.
* **FR-5:** Программа должна поддерживать работу с английской и русской раскладками (через словарь нормализации).
* **FR-6:** Программа должна сохранять отчет о тесте (дата, модель, залипшие клавиши, комментарий) в папку `checks` в формате JSON.
* **FR-7:** Программа должна предоставлять возможность просмотра, редактирования и удаления сохраненных отчетов через меню «Файл».
* **FR-8:** Программа должна собираться в исполняемый файл `.exe` с помощью PyInstaller.

## 3. Нефункциональные требования (NFR)
* **NFR-1:** Язык разработки — Python 3.9+.
* **NFR-2:** Использование только стандартной библиотеки (`tkinter`, `json`, `os`, `glob`, `datetime`) и PyInstaller для сборки.
* **NFR-3:** Интерфейс программы должен быть интуитивно понятным.
