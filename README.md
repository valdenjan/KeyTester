# KeyTester - Тестер клавиатуры

Desktop-программа на Python (Tkinter) для проверки работоспособности клавиатур и сохранения отчетов.

## Установка и запуск

**Вариант 1: Запуск из исходного кода**
1. Установите Python 3.9+.
2. Запустите программу командой:
   `python test.py`

**Вариант 2: Запуск готового .exe файла**
1. Скачайте архив с программой и распакуйте его.
2. Убедитесь, что рядом с `KeyTester.exe` находятся папки `layouts` и `checks`.
3. Запустите `KeyTester.exe`.

## Использование
1. Выберите форм-фактор клавиатуры в меню **«Форм-фактор»**.
2. Нажимайте клавиши на физической клавиатуре — они будут подсвечиваться на экране.
3. Если клавиша не отпустилась (залипла) или вы хотите зафиксировать результат, нажмите **«Файл -> Сохранить отчет»**.
4. Введите модель клавиатуры и комментарий (если нужно).
5. Просмотреть или изменить отчет можно через **«Файл -> Открыть отчет»**.

## Сборка в .exe (для разработчика)
Для создания автономного файла используется PyInstaller:
`pyinstaller --noconsole --onefile --icon=icon.ico test.py`
*Примечание: папки `layouts` и `checks` должны лежать рядом с получившимся `.exe` файлом.*
